# 🚀 DubbyToken

DubbyToken is a transparent, community-focused ERC20 token with custom features for security and sustainability. Built entirely in Solidity and deployed manually via Remix and MetaMask.

## 🌐 Live Deployment
- **Contract Address:** `null`
- **Network:** Base / Ethereum / BSC

## 📜 Features
- ✅ 5% transfer tax (sent to tax wallet)
- ✅ Launch block protection (anti-sniping)
- ✅ Blacklist system
- ✅ ETH deposit and tracking system
- ✅ OnlyOwner functions for control

## 🧠 Smart Contract Overview
- **Language:** Solidity ^0.8.x
- **Tools Used:** Remix, MetaMask
- **Contract File:** `/contracts/DubbyToken.sol`

## 🚀 How to Deploy (Manual Steps)
1. Open [Remix](https://remix.ethereum.org)
2. Paste your smart contract into a new file (`DubbyToken.sol`)
3. Compile using Solidity version ^0.8.20
4. Connect MetaMask to your target network (e.g., Base or Ethereum)
5. Deploy directly from Remix using the injected Web3 environment
6. Save the contract address and verify it on a block explorer

## 🔒 Security
Contract includes protections like blacklisting, launch-block delay, and safe math. Audit is recommended before full public launch.
